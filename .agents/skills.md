# Luxe E-Commerce - Project Skills

## General Tools
- `npm run dev`: Start frontend dev server
- `npm start`: Start backend server
- `npm run build`: Build frontend for production
- `npm run lint`: Lint frontend files

## Agent Coordination
If you need to escalate a task, consider which agent to invoke based on their specialty:
- **Design Agent:** Escalate when tasks involve layout changes, Awwwards aesthetics, GSAP animations, or CSS/Tailwind tweaks.
- **Refinement Agent:** Escalate when tasks involve code cleanup, removing duplication, performance tuning, or database schema updates.
- **Testing Agent:** Escalate when tasks involve bug-fixing, API testing, writing unit tests, or checking UI regressions.
